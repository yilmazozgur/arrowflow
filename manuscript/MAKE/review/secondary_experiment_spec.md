# Concrete experiment specification before result inspection

Status: production design frozen on 2026-09-11 after independent implementation/correction review, 236 passing revision tests in both development and a fresh Python environment, and successful training-only pilots. No confirmatory outer-fold score has been inspected. The four production protocol copies are in experiments/make_revision/protocols/2026-09-11. This document specifies the study and does not report completed confirmatory experiments. The full design is retained: the combined sampled timing projection is 35.48 serial hours, with at most 16 single-thread workers and at least 20 GiB working-space headroom.

## Common design and separate questions

Use the saved five outer folds × three repetitions and three inner folds. Retain all three fitting seeds, unit sample weights, CPU execution with one numerical thread per process, stable numerical-ID ties, and no augmentation. Fit every data-dependent transform within its training partition. Save per-example predictions, fit failures, all candidate scores, selected configurations, encoded-array hashes, dataset/split/source hashes, fit/encoding/inference times and seeds.

E02 answers the full-pipeline prediction question with independently tuned methods. E03–E04 answer the learning-mechanism question using a prespecified common unsupervised representation and fixed network-training settings. They are different estimands and must have separate tables. An E03 fixed configuration is not presented as the best ArrowFlow configuration found by E02.

Stochastic seed averages are within outer fold; fold averages and paired corrected resampled-t intervals follow the main protocol. Neither seed replicates nor corruption replicates are counted as independent datasets. Report the approximate nature of the interval. Primary contrasts, on each of the seven tabular datasets, are:

1. Trained versus untrained final hidden representation of the fixed two-hidden-layer network, with the same kNN probe.
2. The fixed two-hidden-layer ArrowFlow output rule versus corrected footrule kNN on its shared encoded inputs.

These 14 contrasts form the Holm family if inferential significance claims are made. Other comparisons are descriptive, with effect sizes and clearly identified uncertainty; do not promote a favorable secondary contrast into a primary one after seeing results.

## E02 — seven tabular datasets

## E03–E04 — fixed common representation and paired probes

For every fit partition, build one random Gaussian projection of standardized degree-two polynomial features into 32 scores, using a recorded projection seed. Rank scores with the canonical tie rule. This encoder is label independent after the training rows are chosen. Every comparator receives byte-identical ranking arrays; assert equal hashes and row alignment. Fit exactly one encoder per inner/outer training partition and reuse it across all architectures, all three network seeds, trained/untrained states, footrule/Borda and HDC. Encoder randomness is held fixed in this study, not treated as another fitting replicate.

Use the deterministic seed derivation uint32(first four bytes of SHA256(canonical_json([base_seed, stream_parts...]))), interpreting bytes in big-endian order. The base encoder seed is 51047; stream parts are dataset ID, outer repetition/fold, inner-fold index (−1 for final outer fitting), degree, strategy and view index. The E03 view index is 0, and neither architecture nor network seed enters this encoder key. Save fitted imputation means, polynomial powers/order, scaling arrays and projection matrices (or their content hashes alongside reconstructible seeds), plus every shared train/query encoding hash. Network initialization streams use the declared fitting seed as base and include dataset/split/architecture identifiers.

Fixed ArrowFlow settings: batch size 32,200 batch updates, learning rate 0.5, multistep schedule, selected-prototype fraction 0.5, motion-normalization multiplier 0.125, correct-example acceptance probability 0.01, trainable output head. Use three architectures:

- one hidden layer of 64 prototypes;
- two hidden layers of 64 and 32 prototypes (primary);
- one hidden layer of 128 prototypes (approximate storage/inference comparator).

At input vocabulary 32, the two-hidden-layer and 128-wide alternatives both store 4096 hidden prototype entries; their output-state sizes differ and must be included in the actual budget table. Do not call them exactly parameter matched.

Preserve the initial network before training, including output prototypes, and train its copy. Extract the ranking at **each** hidden layer for training and query data by the verified forward computation. Fit probes on inverse item positions using exact Manhattan/footrule distance. Order neighbors by (distance, original training sample ID); keep training rows in ascending global sample-ID order and use stable full-distance sorting, including the cutoff. Class-vote ties select the lowest class ID. Distance weighting uses inverse distance, except that if any selected neighbor has zero distance, only selected zero-distance neighbors vote, with equal weights.

For each architecture/depth, choose a shared kNN configuration from k in {1,3,5,11,21} × weights in {uniform,distance}, maximizing the average inner-fold accuracy across **both** trained and untrained representations and all three seeds. Break a tied score by canonical configuration ID. Both members of the final pair use this same chosen configuration, architecture, initial state and encoding. This symmetric probe-selection rule avoids choosing the probe in favor of either representation. It does not optimize ArrowFlow's training settings. Cache each trained/untrained representation once per split/architecture/network seed, then evaluate all ten probe settings on those arrays; never refit a representation separately for each k.

Tune encoded-input footrule kNN on its own inner scores from the same 10 candidates. Form one classwise Borda prototype by sorting training mean item positions, then use footrule distance and lowest class-ID ties. Include ArrowFlow's output predictions separately. Retain all outputs even when training damages a representation.

Training the representation on a partition and fitting its kNN readout on that same partition is allowed; validation/test representations must be computed by that frozen fitted network. Every inner fit refits the network using only that inner training partition.

## E08–E09 — native rankings and specified HDC control

SUSHI uses exactly sushi3a.5000.10.order and sushi3.udata from the cached provider archive. The full rankings contain each ID0–9 once. Provider-documented corresponding rows join rankings to users; unique user IDs and equal row counts are validation checks. Target is childhood East/West, **one-based user column 7**, counts 3258/1742. See sushi_data_audit.json for hashes and the 105 disagreements with legacy labels. Dataset ID must distinguish this target correction.

Use the same nested folds/seeds and report SUSHI separately from the 14 primary tabular contrasts. Compare dummy, numeric SVC/RF/MLP/kNN/gradient boosting on inverse positions, footrule kNN, Borda, the fixed ArrowFlow architectures, and the HDC model below. Native rankings bypass numerical encoding. For an approximate storage comparison to architecture[64,32], the wider single layer is 230 prototypes: it stores 2760 total entries including a two-class head versus 2752 for the two-layer network. Record both counts and measured cost.

The HDC control binds an independent bipolar item vector to an ordered bipolar position vector, sums over items, and uses normalized class centroids with cosine similarity. Use dimensions 1024 and 10000, inner-selected over all three fitting seeds.

Define the position code precisely. Starting from one random bipolar vector and a random permutation of its D coordinates, flip the first floor(p D / (2(V−1))) coordinates for position p=0,...,V−1. Endpoint vectors differ in exactlyD/2 coordinates for the chosen even dimensions. This implements the ordered-level construction described by Rahimi et al., SectionIII.A.2; here the value is an item's rank position. Independent item keys provide the field labels. Bundle z(pi)=sum_v item_key[v] * position_code[position_pi(v)] elementwise. L2-normalize each sample bundle, average training bundles by class, then L2-normalize each class vector. A zero-norm bundle or class remains zero; cosine ties choose the lowest class ID. Do not binarize the sum or silently substitute a gradient-trained HDC readout. This is one documented adaptation, not a reproduction of the biosignal task or a representative of all HDC models.

Apply HDC to the same shared encodings in the tabular panel and directly to SUSHI. Record both item/position-key seeds and projection seeds. Compute bundles in batches to avoid materializing an N×V×D tensor. Do not redistribute raw SUSHI files: the provider README requires permission for redistribution. Preserve local evidence and release acquisition instructions and source hashes.

## E05 — view, initialization and output-head ablations

Use Iris, Wine and Digits, all saved outer splits and fitting seeds. Fix architecture[64,32] and E03's training settings. Compare prefixes of 1,3,7 views in each of:

1. the same fitted random projection, different prototype initializations;
2. different random projections with matched initialization-seed assignments;
3. strategies cycling random, calibrated, target-aware, with different projection seeds.

All views have degree 2 and 32 coordinates; target-aware LDA uses the verified effective-rank guard and lda_ratio 0.3. Train seven views per condition and reuse prefixes rather than refitting 1/3/7 independently. Repeat each condition with output-head updates enabled/disabled. Seeds are derived deterministically from the outer-fold ID, replicate seed, view index and declared stream type. Keep the same initial prototypes across the two head conditions.

The exact network stream is derive_seed(fit_seed,"e05_network",dataset,repeat,fold,view_index), excluding scheme and head. The projection stream is derive_seed(encoder_base,"e05_encoder",dataset,repeat,fold,fit_seed,strategy,projection_view_index). The shared-projection scheme uses random/view0 throughout; different-random uses each view index; mixed uses its declared strategy and view index. The first view therefore matches across all three schemes. Encoder randomness varies across fitting replicates in E05, unlike E03. Assert identical prototype, accumulator and RNG states for the two head conditions before fitting, and an unchanged head afterward in the frozen condition.

Save every view's prediction and the majority vote for each prefix. Report individual error, mean single-view error, first-view error, ensemble error and the corresponding changes; do not select the best single view using outer scores. Measure disagreement, double fault and pairwise error correlation, marking undefined correlations explicitly. Separately report within-layer duplicate prototypes, normalized pairwise footrule distances, and held-out response-tie frequency. These observations do not imply independent errors.

Within-layer diagnostics use all unordered prototype pairs: duplicate fraction (M−unique)/M, zero-distance pair fraction, and mean/min/max footrule distance divided by floor(V²/2). Query response diagnostics are the fraction of rows with any tied prototype distance and the mean repeated-response fraction 1−unique_distances/M. Error correlations are null with an explicit reason when either error vector is constant. All 5670 logical view/head fits remain in the expected schedule even if an implementation reuses an exactly identical fit with an explicit alias record.

## E06 — scoped corruption study

Use Wine and Digits. Fit on clean training partitions and freeze models before perturbing query inputs. Compare raw-feature SVC/RF/kNN, fold-standardized row-ranking SVC/RF/kNN (input item positions), fixed native-ranking ArrowFlow, and fixed projected ArrowFlow. Tune conventional controls within their own training representation using the E02 grid. Native ArrowFlow receives the row ordering after training-fitted imputation/scaling; projected ArrowFlow uses E03's encoder. Thus “native” in this numeric ablation is a declared preprocessing condition, not native preference data.

The row-ranking conventional pipeline fits raw-feature imputation/scaling, converts rows to orders, then applies the reviewed native pipeline: inverse positions, with a further training-fitted position scaler for SVC/kNN and no such scaler for RF. Every step is refitted within each inner training partition. The final projected AF uses the same encoder and network seed formulas as the corresponding E03 deep model. Fixed AF settings require three final fits per representation and outer fold, without an unnecessary inner AF search.

Define Gaussian noise in coordinates standardized by training means and standard deviations (zero training scale uses 1), then map back to input units before each frozen pipeline. Use severity tau in {0,0.1,0.25,0.5,1}. Isotropic noise has covariance tau²I in these coordinates. Heterogeneous noise uses fixed feature-order multipliers linearly spaced from 0.5 to 1.5 and normalized to mean squared multiplier 1. Correlated noise uses covariance tau²(0.5I+0.5 11ᵀ). Use common stored Gaussian draws across models, with three separate corruption seeds, scaling the same draw across severities.

For quantization, round standardized features to steps {0,0.1,0.25,0.5,1}, with 0 meaning unchanged. For masking use probabilities {0,0.05,0.1,0.2,0.4}, shared uniform masks, and NaNs imputed by the frozen training means. Quantization is deterministic conditional on data; do not replicate it as independent noise. Report absolute error and change from the matched clean model; average corruption seeds before fold-level uncertainty. Do not claim partial-ranking support.

## E07 — degree study

## Design-review resolutions implemented before the production seal

The independent review in task-5-design-review.md found no blocking leakage flaw and identified six important specifications to complete. The fixed encoder stream, exact footrule probe and representation cache are now explicit above. The resolved specifications are:

- **Degree and robustness:** reuse the frozen E07 fits for an additional crossed subset: isotropic and correlated Gaussian noise at tau 0.1 and 0.5, applied at every feasible degree, using E06's same three base corruption draws. Report clean and corrupted error and change from clean for every degree. This supports a limited degree-by-noise comparison; it does not run the full E06 factorial or imply a universal degree effect.
- **Corruption semantics:** both ArrowFlow variants use architecture[64,32], trainable head and the full fixed E03 training settings. Standardized quantization is q(t)=step*rint(t/step), origin 0, NumPy's nearest-even half-step rule; step 0 returns the unchanged input. For each corruption seed/split draw a standard-normal matrix G of shape N×(d+1). Isotropic uses G[:,1:]; heterogeneous uses those columns times the fixed RMS-normalized feature multipliers; correlated uses sqrt(0.5)*G[:,1:]+sqrt(0.5)*G[:,0,None]. Gaussian draws and masking uniforms have separate stream keys, with base corruption seeds 104729,130363,155921. Keys include dataset ID, outer repetition/fold and stream type, and exclude model/degree/fitting seed. Mask every severity by thresholding the same uniform array, giving nested masks. Save raw corrupted-query hashes and assert identical arrays across eligible models before preprocessing.
- **SUSHI folds:** prepare a new manifest from the audited corrected target, with source-row IDs 0–4999 and provider user IDs preserved locally. Generate 5×3 outer/3 inner stratified splits using seed 27183 and Task 4's exact splitter, and save split/content hashes before fitting. Do not reuse an old SUSHI fold file or include user IDs in a public package.
- **Shuffle fixture:** use Iris, outer repetition 0/fold 0, **inner fold 0**. Permute only its inner-training labels with NumPy RandomState seed 109387; retain original inner-validation labels. Fit the fixed E03 two-hidden-layer ArrowFlow model on that inner training set, with the shared encoder and fitting seed 8129. Save input/split/label/prediction hashes, class counts and validation predictions; report the result descriptively alongside the majority-class reference. No core-panel outer labels or scores enter this prerequisite.
- **Compute gate:** exact job counts and family-specific timing/RSS pilots are recorded implementation outputs. E05 has 45 outer splits ×3 network seeds ×3 view schemes ×2 head settings ×7 views =5670 view fits before reuse. E03/E04 have 105 outer splits ×(3 inner partitions+1 final partition) ×3 architectures ×3 seeds =3780 trained-network fits, with initial states reused and probe settings evaluated from cached representations. Native SUSHI contributes 15×4×3×3 =540 such fits. These counts exclude cheap classifier/probe fits and the separate E02 selections. Cache HDC bundles per(rank-array hash,D,item-key seed,position-key seed). The host has 32 logical CPUs and 125GiB RAM; plan at most 16 single-thread worker processes, subject to measured peak memory.
- **Resource contingencies:** if measured runtime/memory makes the full design unattainable, first drop optional extra conventional SUSHI MLP/gradient-boosting fits, then reduce E05's dataset panel before reducing its essential 1/3/7 view and three diversity conditions, then reduce E06/E07's dataset panel while retaining their stated noise types and crossed degree subset. Do not reduce the core seven-dataset E02/E03/E04 comparisons, outer repeats, primary contrasts or recorded fitting seeds based on observed accuracy. Any change requires a revised pre-score specification and repeat timing estimate.

The source hash seal must include every comparator, data loader, seed helper, study runner and specification used for the run. Confirmatory summaries must reconcile results and logs with the complete expected job/fold/seed schedule and reject incomplete evidence.

**Degree-control refinement:** E07 uses PolynomialFeatures(include_bias=true) at every degree, including degree1, so the monomial ordering is nested. For all degrees reuse E03's degree2 encoder-seed key. Generate the Gaussian matrix in row-major monomial order; the first rows are then identical for monomials shared by successive degrees. The centered bias column is identically zero. Assert matching monomial powers and projection rows in tests. This prevents changing the degree from also replacing every common-feature projection coefficient. E02 retains its verified encoder path and default settings; this explicitly named controlled encoder is confined to the degree ablation.

The degree study selects only the input-footrule readout inside inner folds. Its fixed AF therefore needs 8 feasible dataset/degree combinations ×15 outer folds ×3 seeds =360 final fits; the readout requires 360 inner encoders and the final comparisons share 120 outer encoders. One saved corruption bank per dataset/outer fold supplies all degrees, with Wine/Digits raw hashes matching E06. The default bank contains one clean reference, 45 Gaussian cases, five quantization cases and 15 masking cases; E07 takes its declared clean and crossed Gaussian subset. Repeated zero-severity arrays are identical references, not independent uncertainty replicates.
